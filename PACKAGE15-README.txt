DocsFiles Package 15 — Pixel Comes Alive

Adds more visible mascot motion while preserving the working Package 14 fetch assistant:
- gentle breathing and tail wag while Pixel waits
- animated welcome wave
- sniff trail before digging
- moving paws and dirt while searching
- fetched file visibly flies back and appears with Pixel
- stronger celebration/treat animation
- "no match" head shake
- live Pixel status chip (On duty, Sniffing, Digging, File found, Treat time)
- reduced-motion accessibility support

Install from the DocsFiles project root:
unzip -o ~/Downloads/Package15-Ready.zip
npm run build
npm run dev -- --webpack
