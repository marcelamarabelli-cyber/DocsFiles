PACKAGE 14 — PIXEL SEARCH ADVENTURE

Adds a richer, deliberate Pixel fetch sequence:
- Fetch button and Enter-to-search behavior
- Sniffing phase before digging
- Digging paw trail and dirt animation
- File-return celebration
- Faster tail wag during success
- Bone/treat reward with visible treat message
- "Crunch! Good boy" reward follow-up
- Fetched badge on returned file results
- Reduced-motion support retained

TEST:
1. npm run build
2. npm run dev -- --webpack
3. Open a client portal with at least one uploaded document.
4. Search by part of its filename and press Enter or click Fetch.
5. Watch Pixel sniff, dig, return the file, celebrate, and earn a bone.
